# v0.3.0 — Home Content Management v1

`GET /home` consumes structured content managed by ElDokan Admin 1.9.0.
It adds `hero_slider` and `banner_grid` to the ordered section union.
Only enabled records for the effective `ar` or `en` language and current
schedule are returned. Attachment IDs remain internal; responses contain
normalized image objects and opaque `hsl_*` / `hbn_*` identifiers.

ProductDetail and all non-Home endpoints are unchanged.
