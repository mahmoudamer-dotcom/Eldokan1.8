# ElDokan Customer API 0.1.0 — Read-only Catalog Foundation

## Goal

Create the first production-testable ElDokan-owned Customer API contract implementation on top of WooCommerce.

## Implemented

- Health endpoint.
- Homepage read model.
- Categories and subcategories.
- Category-specific configured attributes.
- Product listing with pagination.
- Product search.
- Category/brand/price/stock filters.
- Basic sorting.
- Product details.
- Variable product variations.
- Product images and attributes.
- Seller projection using ElDokan ownership metadata with legacy fallbacks.
- WPML-aware language switching for `ar` / `en`.
- Search suggestions.
- Stable ElDokan response envelope and opaque public IDs.

## Not implemented

- Cart and guest session.
- Checkout.
- Payment processing.
- Customer authentication.
- Wishlist server sync.
- Follow Seller.
- Price Tracker.

## Design rule

The React frontend must consume the ElDokan API contract and must not depend directly on WooCommerce response formats.
