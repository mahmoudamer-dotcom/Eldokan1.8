# v0.3.1 — Home Release Hardening

This patch preserves Customer API Contract v1 and the existing `GET /home` response shape.

## Fixes

1. Home schedule evaluation now uses the WordPress site timezone consistently. Stored `Y-m-d H:i:s` values are parsed with `wp_timezone()` and compared to `current_datetime()`; the previous mixed `current_time('timestamp')` + `strtotime()` path is removed.
2. Search CTA values are sanitized as human search text instead of title/category slugs. Category CTA values remain slug-sanitized.

No endpoint, schema, cache-generation or permissions behavior is intentionally changed.
