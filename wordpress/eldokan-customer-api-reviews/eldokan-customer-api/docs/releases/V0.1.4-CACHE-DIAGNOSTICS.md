# ElDokan Customer API 0.1.4
## Cache Diagnostics

Live testing showed repeated identical product-list requests returning:

```text
X-ElDokan-Cache: MISS
```

even when refreshed immediately.

This release does not change the public JSON contract.

It adds enough diagnostics to distinguish between:

- changing cache key;
- changing cache generation;
- cache write failure;
- cache backend read-back failure;
- successful write that is not reused on the next request.

New headers:

```text
X-ElDokan-Cache-Generation
X-ElDokan-Cache-Key
X-ElDokan-Cache-Backend
X-ElDokan-Cache-Store
```
