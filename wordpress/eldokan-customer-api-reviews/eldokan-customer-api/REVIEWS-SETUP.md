# التقييمات ومنتجات البائع — Customer API 0.9.1

## التثبيت

1. من WordPress افتح Plugins → Add New → Upload Plugin وارفع `artifacts/eldokan-customer-api-0.9.1-reviews.zip`.
2. اختار استبدال النسخة الحالية من **ElDokan Customer API** ثم تأكد إنها مفعّلة. لا تثبّت نسخة ثانية بجانب القديمة. النسخة دي مبنية على 0.8.6، وفيها تعديلات الشحن والدفع والتقسيط وإلغاء الطلبات السابقة.
3. فعّل تقييمات المنتجات من WooCommerce → Settings → Products → Enable product reviews. المنتج نفسه لازم يسمح بالتقييمات.
4. تحديث واجهة المتجر والـAPI client موجود في المشروع؛ انشر الواجهة المحدثة علشان يظهر الربط. إعادة تشغيل خادم التطوير مطلوبة لو لسه بيستخدم ملفات الـclient القديمة.

## تجربة العميل

- تفاصيل المنتج تعرض اسم البائع ورابط واضح لمنتجاته وتقييماته. صفحة البائع تعرض الاسم والتقييم والمنتجات فقط؛ لا تعرض بيانات اتصال أو بيانات شخصية.
- تقييم المنتجات وتعليقاتها أصبحت محفوظة في WordPress، وليست في المتصفح. تقييمات المتصفح القديمة لا تُنشر تلقائيًا؛ لم يتم حذف بياناتها المحلية.
- العميل يسجّل دخوله أولًا. تقييم المنتج يحتاج شراء معترفًا به بواسطة WooCommerce. تقييم البائع يحتاج طلبًا بحالة Processing أو Completed يحتوي على هوية البائع المحفوظة وقت الطلب (`_eldokan_seller_user_id` على بند الطلب).
- تقييم واحد لكل حساب ولكل منتج أو بائع. العميل يقدر يعدّل أو يحذف تقييمه فقط. الجديد والمعدّل ينتظر المراجعة؛ المتوسط يُحسب من المنشور فقط.
- التعليق غير فارغ، بحد أقصى ٢٠٠٠ حرف، والتقييم من نجمة إلى خمس نجوم. اسم حساب العميل يظهر، البريد والهاتف لا يظهران.
- قائمة المنتجات في صفحة البائع مقسّمة إلى صفحات من الـAPI. «الأكثر مبيعًا في القسم» يستخدم `total_sales`، ويعرض المنتجات المتاحة ذات المبيعات الفعلية. لا يظهر القسم لو مفيش منتجات مطابقة.

## مراجعة التعليقات

- تقييمات المنتجات: WooCommerce → Products → Reviews (قد تظهر ضمن Comments حسب نسخة WooCommerce).
- تقييمات البائع: Comments، واختر نوع **ElDokan seller reviews**. التعليق يوضح البائع والنجوم للمشرف. استخدم Approve / Unapprove / Spam / Trash.
- الطلبات القديمة اللي مفيهاش هوية البائع في بنودها لا تمنح صلاحية تقييمه. لا نستنتج البائع من الموظف الذي نشر المنتج.

## الـAPI client

النسخة المحلية `@eldokan/customer-api-client` أصبحت 0.7.1. الملفات المصدر و`dist` ومواصفات OpenAPI محدثة.

```ts
await api.reviews.list('prd_5526', { page: 1, perPage: 10 });
await api.auth.session();
await api.reviews.mine('prd_5526');
await api.reviews.create('prd_5526', { rating: 5, comment: 'My purchase experience...' });
await api.reviews.list('sel_123');
await api.sellers.products('sel_123', { page: 1, perPage: 48 });
await api.products.bestSelling('electronics', { perPage: 5 });
```

التعديل والحذف عبر `api.reviews.update(target, reviewId, input)` و`api.reviews.remove(target, reviewId)`؛ الطفرات تتطلب جلسة العميل وCSRF، والواجهة تمر عبر BFF نفس الدومين. قراءة `mine` خاصة بصاحب الحساب ولا تُخزّن في كاش الكتالوج.

## حدود المراجعة المحلية

تمت مراجعة TypeScript وESLint. لا يوجد PHP أو WordPress محلي لتشغيل الإضافة، ولم يتم تنفيذ طلب شراء أو نشر تقييم على المتجر الحقيقي. يلزم تجربة النسخة على بيئة تجريبية قبل اعتمادها للإنتاج.

## إضافات مقترحة لاحقًا

صور مع التقييمات، رد البائع على التعليق، زر «التقييم مفيد»، وإبلاغ عن إساءة. لم تُضف هذه الميزات ضمن النسخة الحالية.
