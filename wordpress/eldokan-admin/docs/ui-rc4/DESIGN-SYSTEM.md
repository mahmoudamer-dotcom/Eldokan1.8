# نظام واجهة Admin Staff — RC4

حافظ RC4 على اسم ElDokan وألوان RC2 المشتقة من الإضافة، دون استبدال العلامة أو تحميل خط أو إطار عمل جديد. التصميم مطبق على قوالب PHP الأصلية وشاشة Stories الأصلية داخل WordPress.

| العنصر | القاعدة |
|---|---|
| نص وأس surfaces | #172b45، ثانوي #52647b، خلفية #f3f5f9، حدود #dce3ed |
| الإجراء الأساسي | #2255c8، نص أبيض، focus ظاهر 3px |
| المقاسات | تباعد 4/8/12/16/20/24؛ استدارة 6 للحقول، 9–12 للأسطح |
| الطباعة | خطوط النظام وSegoe UI/Tahoma/Arial؛ تدرج title/header/description، أرقام tabular |
| التنقل | ست مجموعات في قائمة WordPress للمدير الكامل؛ روابط فرعية سياقية ومسار صفحة، مع إبراز المجموعة الفعلية |
| الإشعارات | منطقة WordPress طبيعية خارج hero؛ الاحتفاظ بعقدة التنبيه وأحداثها؛ لا إخفاء تنبيهات إضافات أخرى |
| الجداول | رأس واضح، صفوف متسقة، تمرير داخلي قابل للتركيز، كثافة اختيارية، بحث ظاهر بأنه في الصفوف المحملة فقط |
| المنتجات | pagination من الخادم مع عدد النتائج والصفحة، وفلاتر GET الأصلية؛ لا ادعاء بحث شامل من أداة الصفوف المحلية |
| ملف التاجر | تفاصيل اختيارية مفتوحة مبدئيًا، طي/فتح الكل، الرابط يفتح قسمه وأخطاء الحقول تكشف النموذج |
| النماذج | نفس action/method/field names/nonce؛ labels/focus وvalidation feedback؛ لا إرسال تلقائي أو تغيير قيد عمل |
| التأكيد | native dialog مع إلغاء أولي وEscape واستعادة focus؛ التأكيدات القديمة التي تملك معالجًا تبقى على سلوكها الأصلي |
| الانتظار والفراغ | no records/no matches ونصوص نجاح/خطأ؛ لا skeleton أو loading وهمي لمسار لا يجلب بيانات |
| الملخصات المالية | تنبيه مصدر ونطاق عينة واضح وروابط التقرير التفصيلي؛ لا وصف العينة كرصد رسمي |
| الاستجابة | grids/forms مرنة، عمود واحد تحت 700 وأحجام touch محسنة؛ يجب قبول هندسة المتصفح والتمرير على staging |

كل محدد في admin.css وworkspace.css يبدأ بـ`.eda-admin-screen`. خدمة ElDokan_Admin_UI تتحقق من allowlist الشاشة/hook الفعلي، وتحمّل الأصول هناك فقط. لا styles على :root/html ولا تعديل لقوائم Woo أو WCFM. JavaScript لا يضيف fetch أو CDN أو writes. Chart.js CDN كان موجودًا في المصدر السابق وما زال اعتماد dashboard قائمًا؛ لم نضف مكتبة خارجية جديدة.

العربية تستخدم text domain الأصلي eldokan-admin وPO/MO/POT، واتجاه WordPress وخصائص CSS المنطقية. احتُفظ بـ652 ترجمة سابقة وأضيفت/نقحت 29 رسالة؛ كتالوج اليوم 680 مدخلًا فريدًا. بيانات المتاجر والمعرفات لا تُترجم. بعض نصوص الوحدات التاريخية ما زالت مختلطة؛ لا ندعي اكتمال تعريب كل أداة legacy.

المعاينات تستعمل نفس templates/assets بعد تنفيذ تحسينات DOM، لكنها ليست دليل WCAG أو قارئ شاشة أو قياس browser. قائمة القبول تحدد اختبارات keyboard/dialog/mobile/native editor المطلوبة.
