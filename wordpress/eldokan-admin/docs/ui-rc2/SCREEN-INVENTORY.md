# حصر الواجهات

المصدر المرفق هو المرجع؛ لا توجد صفحات مخترعة. الشاشات التالية تتلقى النظام المشترك، مع المحافظة على عناوينها ومساراتها التشغيلية.

| الشاشة / المعرّف | المكونات الحالية والتحسين |
|---|---|
| `eldokan-admin` | مؤشرات وروابط تشغيل ورسومان؛ ترويسة وبطاقات مختصرة |
| `eldokan-admin-sellers` | بحث وترقيم، حسابات شركات، حالات وتقييمات؛ جدول وتمرير وكثافة اختيارية |
| ملف التاجر داخل sellers | الحالة والحسابات والأدوار والوصول والتقييمات والعمولات والكشوف والمنتجات والطلبات؛ مكونات موحدة |
| `eldokan-admin-registrations` | بحث وحالة وتواريخ وترقيم وتفاصيل PDF واعتماد/رفض/حذف؛ فلاتر مرنة وإجراءات واضحة |
| `eldokan-admin-products` | بحث وحالة وقسم وأسعار ومخزون وتحكم رسوم وتحرير؛ تحسين عرض الجدول والنموذج |
| `eldokan-admin-orders` | بحث وتاجر وحالة وتواريخ وتحديث الطلب وترقيم؛ فلاتر مرنة وعرض موحد |
| `eldokan-admin-categories` | أقسام وروابط المنتجات ورسوم وخصائص؛ نماذج وجداول موحدة |
| `eldokan-admin-reports` | اختيار تاجر وفترة وتصدير PDF/Excel وماليات ومنتجات وإلغاءات؛ أسطح وجداول مشتركة |
| `eldokan-admin-commissions` | صفحة مسجلة مخفية أصلًا من القائمة: إضافة/حذف قواعد؛ وصول سياقي وتنبيه حذف |
| `eldokan-admin-statements` | صفحة مسجلة مخفية أصلًا: كشوف حساب؛ جدول موحد |
| `eldokan-admin-performance` | صفحة مسجلة مخفية أصلًا: أداء وتقييمات؛ جدول موحد |
| `eldokan-admin-activity` | فلاتر وتصدير CSV وتفاصيل أحداث؛ فلاتر مرنة وتمرير الجدول |
| `eldokan-admin-email-settings` | مرسل وشعار وقوالب ورسالة اختبار؛ نماذج متسقة |
| `eldokan-admin-settings` | تكامل وروابط إعدادات متقدمة؛ ترويسة وروابط مشتركة |
| `eldokan-admin-team-permissions` | أدوار موظفين ومجموعات صلاحيات وحفظ واستعادة؛ شبكة أوضح وتمييز الحساس والمحدد |
| `eldokan-admin-dashboard-control` | صفحة مسجلة مخفية أصلًا: إعدادات لوحة التاجر؛ النظام المشترك |
| `eldokan-admin-access-roles` | صفحة مسجلة مخفية أصلًا: قوالب أدوار التاجر؛ النظام المشترك |
| `eldokan-admin-wcfm-index` | فهرسة وربط وفحص وإصلاح وتقدم وتشخيص؛ مكونات عرض فقط، دون تشغيل أي عملية |
| `eldokan-admin-home` | شرائح وبنرات ووسائط وترجمة وجدولة وترتيب وأقسام؛ نماذج متجاوبة وتأكيد حذف |
| `eldokan-checkout-setup` | إعداد Paymob وCOD والشحن وتقارير التشخيص؛ صفحة متسقة مع اتجاه المستخدم |
| قائمة وتحرير `eldokan_story` | واجهة ووردبريس الأصلية ومنتقي التاجر/المنتج والوسائط والعناوين والانتهاء؛ تنسيق وترجمة فقط |

الروابط المخفية تبقى مسجلة بنفس capability، ويضيف شريط التنقل وصولًا سياقيًا فقط عندما تكون مسجلة ومصرحًا بها. صفحات تحرير منتجات ووكومرس، شاشة المستخدمين العامة، ومدير الوسائط والإضافات الأخرى لا يعاد تصميمها.

حالات الفراغ والنجاح والخطأ الأصلية محفوظة. الجداول الفارغة التي كانت بلا رسالة تتلقى رسالة عرض فقط. عدد التسجيلات يأتي من القائمة الأصلية، ولا تُحسب مؤشرات إضافية.
