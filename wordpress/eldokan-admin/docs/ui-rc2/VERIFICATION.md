التاريخ: ١٧ أكتوبر ٢٠٢٦. هذه نتائج محلية معزولة، وليست قبول ووردبريس حيًا.

|---|---|

| فحص JavaScript | نجح، ٣ ملفات إنتاج، مع تحليل السكربتات المضمنة في القوالب الناتجة |

| مقارنة المصدر | ٢٢٠ دالة أصلية متطابقة نصيًا؛ ٣٢ دالة عرض/أصول تغيرت ضمن قائمة محددة |

## أدلة قابلة لإعادة الفحص

حزمة المراجعة تحتوي مصدر الإضافة الكامل، نتائج JSON، نماذج HTML قبل/بعد، صفحات HTML بعد تشغيل JavaScript في نموذج DOM، وصور PNG وPDF للمقارنات. `VISUAL-REVIEW.html` يعرض المقارنات مع وصف حدودها.

مكتبات jsdom وtinycss2 وWeasyPrint مستخدمة للتحقق خارج الإضافة فقط. لا تُرفق مكتبات الاختبار داخل حزمة الإنتاج ولا يضاف طلب شبكة إلى واجهة الإدارة.

## ما لم ينفذ

- تفعيل الإضافة داخل WordPress حقيقي، أو قبول قاعدة بيانات وWooCommerce/WCFM/WPML/Paymob فعلية.
- هندسة المتصفح الفعلية: مقياس القص والتمرير وقياسات الجداول والموبايل، أو تدقيق وصول رسمي أو اختبار قارئ شاشة.
- جلب المنتجات/التجار عبر AJAX حي، نافذة الوسائط الأصلية، حفظ/حذف فعلي، إرسال بريد، تصدير PDF/Excel حي، أو دفع أو تغيير حالة طلب.
- اختبار التعايش مع ملفات الإضافات المستقلة القديمة؛ لم تُرفق fixtures اللازمة. محمل الوحدات لم يتغير.
- اختبار تحمل على بيانات إنتاج كبيرة أو تغيير WCFM أو تشغيل الفهرسة/الترحيل.

المعاينات ليست صورًا من الموقع الحي أو من جلسة WordPress مكتملة. يستخدم العارض الثابت تكييفًا معلنًا لاستعلامات عرض الشاشة وإخفاء الحقول المخفية والقوائم المغلقة. الرسوم canvas وعناصر المتصفح الأصلية وتفاصيل الشبكة لا يقبلها هذا العرض. تحتوي النماذج تجارًا تجريبيين، وطلبات/منتجات فارغة، ولا يجوز استنتاج جاهزية العمليات من الصور.
