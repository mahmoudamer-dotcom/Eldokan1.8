# التثبيت والرجوع — تجريبي فقط

الحالة: **مرشح غير معتمد**. لا ترفع إلى الموقع الحي قبل قبول مستقل.

1. خذ نسخة ملفات وقاعدة بيانات من البيئة التجريبية، واحتفظ بحزمة rc.1 الأصلية. تحقق من إصدارات المتطلبات الموجودة فعليًا دون تحديث جماعي.
2. استبدل الإضافة الحالية بالحزمة `eldokan-admin-v1.10.0-rc.2.zip` مع بقاء المسار `eldokan-admin/eldokan-admin.php`. لا تثبت نسخة ثانية بمجلد مختلف. اختر الاستبدال إذا استخدمت رفع الإضافات في ووردبريس.
3. لا تعِد تشغيل Checkout Setup أو Stories كإضافات مستقلة. حالة الوحدات المدمجة وآلية التعايش مع الإضافات القديمة لم تتغير.
4. اترك WCFM وWooCommerce وWPML وPaymob وCustomer/Seller API بحالتها الحالية. لا تشغل ترحيلًا أو إعادة بناء فهرس لهذا التحديث.
5. امسح تخزين الأصول المؤقت في البيئة التجريبية وأعد تحميل الصفحة. الإصدار الجديد يغيّر مفاتيح نسخ CSS/JS تلقائيًا.
6. اختبر مستخدمًا عربيًا وآخر إنجليزيًا وأدوار الموظفين، ثم نفّذ قائمة القبول التالية. لا تنفذ شراءً أو دفعة حقيقية ضمن اختبار الشكل.

## القبول المطلوب قبل الإنتاج

- النظرة العامة، القوائم والتنقل وصلاحيات الروابط لكل دور. افتح منتج ووكومرس وإعداداته وصفحات WCFM للتحقق من عدم تسرب التصميم.
- بحث وفلاتر وترقيم التجار والتسجيلات والطلبات والمنتجات مع بيانات كبيرة.
- فتح ملف تاجر وفحص الصلاحيات والرسوم والتقارير، دون تغيير قيم حية.
- حفظ/استعادة صلاحيات على دور تجريبي؛ تحقق من عدم تغير أي صلاحية لم تُحدد.
- إعدادات الدفع: قارن القيم قبل وبعد حفظ تجريبي، واختبر رفض nonce والصلاحية. اختبار Paymob فعلي يكون ضمن مسار قبول الدفع المنفصل.
- قصص: عنوانا اللغتين، التاجر والمنتج والوسائط والترتيب والجدولة والانتهاء، ثم تحقق من نفس استجابة التسليم للعميل.
- محتوى الرئيسية: فتح نافذة الوسائط، حفظ وتعديل وجدولة عنصر تجريبي، وإلغاء الحذف قبل تأكيد حذف عنصر تجريبي قابل للتخلص منه.
- لوحة المفاتيح وEscape والتركيز، عرض ١٤٤٠ و١٠٢٤ و٧٦٨ و٣٩٠ بكسل، والتكبير ٢٠٠٪. اختبر المتصفح مع حجب CDN للرسوم.
- افحص سجل PHP ووحدة تحكم المتصفح وطلبات الشبكة أثناء العمل. لا تعتبر النماذج المحلية بديلًا لهذا القبول.

## الرجوع

استبدل ملفات الإضافة كاملة بحزمة rc.1 الأصلية في نفس المجلد، ثم امسح تخزين الأصول المؤقت. هذه النسخة لا تضيف مخطط بيانات أو ترحيل إعدادات؛ لا يلزم تراجع قاعدة بيانات لمجرد الرجوع عن الواجهة. إذا غيّرت بيانات أثناء القبول، فتعامل معها منفصلة أو استعد نسخة البيئة التجريبية عند الحاجة. لا تحذف الإضافة ولا تشغل uninstall ولا تفهرس أو ترحّل WCFM لإجراء الرجوع.
