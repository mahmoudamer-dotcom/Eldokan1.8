`assets/admin.css` هو أساس الأنماط القديمة بعد عزله. `assets/workspace.css` هو طبقة النظام الجديدة. لا توجد قواعد عامة على `html` أو `:root`. لا يُخفى أي شريط ووردبريس أو إشعار من إضافة أخرى.

`ElDokan_Admin_UI` يحدد الشاشة، يسجل الأصول والترجمة، وينشئ التنقل من القوائم الموجودة مع فحص capability. القوائم الفرعية تستخدم details/summary الأصلية، وتدعم Escape وإغلاق القائمة عند الخروج منها. من دون JavaScript تبقى الروابط والنماذج الأساسية متاحة.

`assets/workspace.js` يضيف تحسينات عرض فقط. لا توجد طلبات شبكة أو تعديل لصلاحية أو مخطط بيانات فيه. لا يبحث عبر API، ولا يعيد إرسال الطلبات تلقائيًا.

## الترجمة والاتجاه

مجال النص `eldokan-admin`؛ الملفات `languages/eldokan-admin-ar.po` و`.mo` و`.pot`. تُحمل ترجمة المستخدم المعتادة في ووردبريس. أسماء الموردين والمنتجات والمعرّفات التقنية تبقى بيانات أصلية. استخدمت خصائص الاتجاه المنطقية وإطار `rtl` لووردبريس، مع عزل رقم الإصدار باتجاه لاتيني.

يدعم النظام تقليل الحركة. التأكيد الجديد يستخدم dialog الأصلي مع تركيز أولي على الإلغاء، استعادة التركيز، ودعم Escape. لا يحل الحوار محل حماية nonce/capability على الخادم.
