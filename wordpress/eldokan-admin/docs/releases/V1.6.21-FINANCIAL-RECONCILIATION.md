# v1.6.21 Financial Reconciliation

- Seller financial reports now read WooCommerce orders directly instead of the WCFM historical index.
- Revenue counts only paid, non-excluded orders and subtracts item refunds/tax refunds.
- Cancelled/refunded/failed/rejected/returned/unpaid lines are excluded from realized revenue.
- Platform commission uses the paid/refund-adjusted item base.
- New orders snapshot the effective fee rule on the WooCommerce order item so later category fee changes do not rewrite historical commissions.
- Legacy orders without a fee snapshot are clearly marked `Legacy/current rule`.
- Reconciliation invariant: Net Sales = Platform Commission + Seller Net.
- Page, Excel and PDF share the same reconciled report dataset.
