# ElDokan Admin v1.6.17

- Reports now support selecting one seller at a time.
- Date range filtering (From / To).
- Summary cards: Total Sales, Platform Commission, Seller Net Revenue, Orders, Units.
- Detailed order-line financial table.
- Download Excel button exports the selected seller/date range as an Excel-compatible .xls file.
- Commission uses the same effective fee priority already used by ElDokan Admin.
- Seller Dashboard was not modified.
