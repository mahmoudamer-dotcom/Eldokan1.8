# v1.6.28 Official Order Workflow

ElDokan Admin order update dropdown now uses the same official Seller Dashboard workflow:
1. New Order
2. Preparing
3. Received from Seller
4. Shipped
5. Delivered

Exceptional statuses remain available: Rejected, Cancelled, Returned, Delivery Failed, Failed, Refunded.

Legacy/internal WooCommerce statuses such as Ready to Ship, Ready for Pickup, On Hold, Completed and Pending Payment can still be displayed on historical orders, but are not offered as normal operational update choices.
