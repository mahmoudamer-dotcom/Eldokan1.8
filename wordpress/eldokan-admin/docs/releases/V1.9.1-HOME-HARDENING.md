# ElDokan Admin 1.9.1 — Home Release Hardening

This patch keeps the Home Management v1 data model, UI, permissions, audit and cache behavior unchanged.

## Fix

- Search CTA values are sanitized as human search text with `sanitize_text_field()`.
- Category CTA values continue to use slug sanitization with `sanitize_title()`.
- URL and product CTA validation are unchanged.

No public Customer API schema change is introduced by this Admin patch.
