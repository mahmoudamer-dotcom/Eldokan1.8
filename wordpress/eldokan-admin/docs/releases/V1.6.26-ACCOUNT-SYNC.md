# v1.6.26 — Dashboard Account Sync

- ElDokan Admin now recognizes the Dashboard API canonical `_eldokan_parent_owner_id` relationship.
- Backward-compatible owner relationship keys are still supported.
- Seller/company account queries now include the current `eldokan_operator` and `eldokan_finance` roles.
- Legacy `eldokan_editor` remains readable for older accounts.
- Existing Dashboard-created accounts become visible under the correct seller/company without requiring recreation.
