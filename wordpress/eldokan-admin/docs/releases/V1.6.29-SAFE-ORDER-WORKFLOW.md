# ElDokan Admin v1.6.29 — Safe Order Workflow

- `Received from Seller` now writes safe WooCommerce status `received-seller`.
- The visible label remains `Received from Seller`.
- Legacy `received-from-sel` / historical long values are treated as the same status in filters.
- Admin verifies that the original WooCommerce order ID still exists immediately after status update.
- No order delete/trash code is used by the workflow update.
