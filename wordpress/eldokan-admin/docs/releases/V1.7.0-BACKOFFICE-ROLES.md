# ElDokan Admin 1.7.0 — Backoffice Roles & Permissions

## Overview

Version 1.7.0 introduces a dedicated roles and permissions system
for ElDokan internal employees.

This system is completely separate from Seller Dashboard roles.

## New Backoffice Roles

- ElDokan Manager
- ElDokan Developer
- ElDokan Staff
- ElDokan Viewer

WordPress Administrator and WooCommerce Shop Manager are not modified.

## Permission Management

A new Team Permissions screen allows administrators to manage
ElDokan employee permissions without editing PHP code.

Permissions include:

- Dashboard access
- Sellers
- Registrations
- Products
- Orders
- Categories and attributes
- Reports
- Commissions
- Activity
- Email settings
- ElDokan settings

## Security

Sensitive capabilities remain restricted.

Examples:

- Permanent seller account deletion
- Permanent product deletion
- Legacy migration tools
- Legacy seller role system
- WCFM migration/index tools

Administrator remains the highest level.

## Product Permissions

Product deletion is intentionally restricted to WordPress Administrator in version 1.7.0.

- View Products
- Manage Products (Create / Edit)

This allows staff members to work with products without receiving
unnecessary deletion privileges.

## Category Permissions

Users with product editing permissions can assign existing categories.

Users with Manage Categories permission can create and edit product
categories and attributes.

Category deletion is not granted to ElDokan custom roles by default.

## Legacy Systems

The following legacy systems remain Administrator-only until they are
reviewed and removed:

- Seller Role Permissions
- Dashboard Control
- WCFM Data Index
- WCFM Migration tools
