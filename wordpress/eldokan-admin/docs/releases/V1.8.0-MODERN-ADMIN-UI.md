# ElDokan Admin 1.8.0 — Modern Admin UI

## Overview

Version 1.8.0 modernizes the ElDokan internal backoffice interface without
replacing the established marketplace business logic.

The release is intentionally UI-focused. Existing WordPress/WooCommerce data,
order workflows, seller ownership, reports, commissions, WCFM migration tools,
nonces and server-side capability checks remain in place.

## Visual System

The admin interface now uses a consistent modern design system with:

- Branded dark ElDokan page headers
- Responsive KPI cards with Dashicons
- Cleaner charts and dashboard navigation
- Modern cards, tables, filters, forms, badges and buttons
- Improved responsive behavior for narrower screens
- Consistent read-only visual states
- A redesigned Team Permissions interface

## Permission-Aware UI

The dashboard now hides links to areas that the current employee role cannot
view.

Orders and Registrations also avoid presenting mutation controls to read-only
users. Server-side permission checks remain the authoritative security layer.

## Security and Business Logic

This release does not grant new broad WordPress or WooCommerce capabilities.

It does not add `manage_options`, `manage_woocommerce` or product deletion to
ElDokan custom employee roles.

The existing `view_admin_dashboard` bridge and WooCommerce admin-access exception
for ElDokan backoffice roles remain unchanged from the 1.7.0 permissions work.
