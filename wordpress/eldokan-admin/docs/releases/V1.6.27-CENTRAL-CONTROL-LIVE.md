# ElDokan Admin v1.6.27 — Central Control LIVE

ElDokan Admin is the central administrative source of truth.

## Central Registrations
- Seller/company public registrations appear in ElDokan Admin → Registrations.
- Pending badge in menu.
- Search by name, email, company, phone, tax number/address.
- Status and date filters.
- Pagination.
- Full registration detail view.
- Secure Verification PDF view.
- Approve / Reject / Delete.
- Approval updates the same `_eldokan_account_status` and roles used by Seller Dashboard login.
- Seller Dashboard team/sub-accounts are explicitly excluded from the Registration queue.

## Sellers
- Seller Control Center remains the central company page.
- Added central seller status switch: Approved / Disabled.
- Dashboard access reads the same account status.

## Orders
- Search by order number, customer name/email/phone.
- Seller, status and date filters.
- Inline WooCommerce order status update.
- WooCommerce remains canonical; existing Seller API order-status synchronization mirrors the update to Seller Dashboard.

## Products
- Added product search and status filter.
- Existing product, stock, fee, seller/company and edit controls preserved.

## Activity
- Existing full audit trail remains active.
- Seller REST API mutations, WordPress users, products, order status changes, admin actions and WooCommerce events remain visible in Activity.

## Email Settings
- Added Approved and Rejected seller registration email templates.
- Same `eldokan_email_settings` option remains shared with Seller API.

No seller-dashboard financial, report, product, order, WPML or permission calculation was replaced.
