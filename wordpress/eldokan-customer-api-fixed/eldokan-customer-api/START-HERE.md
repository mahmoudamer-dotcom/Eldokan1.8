# START HERE — Customer API 0.8.0

الإضافة الحالية هي الإصدار **0.8.0**، والعقد **v1**. تنفيذ المرحلة الحالية مكتمل في الكود، وقبول بيئة الاختبار الحقيقية ما زال مطلوبًا قبل النشر الحي.

## محتويات الحزمة

هذه حزمة WordPress قابلة للتثبيت، بمجلد إضافة واحد يحتوي ملف التشغيل الرئيسي، ملفات includes والتوثيق. أدلة الاسترجاع ونتائج الاختبارات السابقة محفوظة في حزم منفصلة؛ ليست مطلوبة كملفات تشغيل داخل هذه الحزمة.

## ابدأ بالترتيب

1. اقرأ docs/HANDOFF.md للوضع الحالي وحدود التسليم.
2. اقرأ docs/API-CONTRACT.md للعقد العام الكامل، وdocs/ENDPOINT-STATUS.md لقائمة العمليات.
3. راجع docs/SECURITY.md للجلسات والحماية ووصول طلبات الضيوف.
4. راجع docs/TESTING.md لقبول بيئة الاختبار الذي لم يُنفّذ هنا.
5. راجع docs/FILE-MAP.md للملفات المشحونة وCHANGELOG.md لتاريخ التطوير.

إصدارات الحزم المصاحبة:

- Customer API Client 0.6.0
- Developer Portal 1.8.0
- OpenAPI Contract v1

الواجهة تستهلك الـClient الرسمي والعقد العام. مسار API الحالي:

`/wp-json/eldokan-customer/v1`

العناوين البديلة المخطط لها لا تُعتبر منشورة بمجرد وجودها في التوثيق.

التنفيذ يشمل الحساب والهاتف الاختياري والعناوين والمفضلة والسلة والاقتباس ومحاولات الشراء وإنشاء طلب واحد والدفع عند الاستلام والدفع المستضاف وقراءة الطلبات ووصول الضيف وإعادة الدفع على نفس الطلب. احتفظ بمعرّفي المحاولة والطلب عند الغموض؛ لا تنشئ طلبًا آخر تلقائيًا. العودة من صفحة الدفع ليست إثبات دفع؛ اقرأ الطلب المحمي بعد العودة.

لا يبدأ هذا التسليم تنفيذ الواجهة أو توافق تعديل تجهيزات التجار أو الاختبار الحي أو النشر. اختبارات التطوير ونتائجها موجودة منفصلة، ولا يُطلب تشغيل مسارات اختبارات غير مشحونة في هذه الحزمة.
