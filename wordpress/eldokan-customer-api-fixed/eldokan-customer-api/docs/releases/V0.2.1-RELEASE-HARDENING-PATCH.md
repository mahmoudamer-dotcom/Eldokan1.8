# v0.2.1 — Release Hardening Patch

## Purpose

This patch corrects the pre-live 0.2.0 contract without starting Cart, Checkout or customer authentication.

## Changes

- Removed five duplicate `/products` `attributes` parameter definitions from canonical OpenAPI.
- Added automated detection for duplicate OpenAPI operation parameters.
- Removed non-authoritative `customer_state` and seller `followed` values.
- Isolated WPML hooks, object translation and language SQL behind a replaceable translation adapter.
- Added a native-language fallback and truthful `Content-Language` response header.
- Added requested/effective/provider language identity to application cache keys.
- Replaced public WordPress/WooCommerce version details with minimal health readiness.
- Synchronized Developer Portal 1.3.1 and all generated OpenAPI formats.

## Compatibility

All nine routes and the v1 namespace remain unchanged. Removing the personal-state placeholders is an intentional pre-production contract correction; clients must not expect those fields until authenticated customer APIs are implemented.

## Live verification required

Run PHP lint on all nine PHP files, then execute the live matrix in `docs/TESTING.md`, including WPML and no-WPML fallback behavior, Arabic slugs, product translation IDs, attribute filtering, variations, visibility, seller ownership, health readiness and cache diagnostics.
