# Customer API 0.4.0 — Catalog Frontend Phase 1

## Added

- `GET /brands?page=&per_page=&search=&lang=`
- `GET /tags?page=&per_page=&search=&lang=`
- `GET /sellers/{seller_id}?lang=`
- `tag={slug}` on `GET /products`

## Reused instead of duplicated

- Subcategories: `GET /categories?parent={slug}` and `GET /categories/{slug}` → `children`.
- New arrivals: `GET /products?sort=newest` and existing Home `product_carousel`.
- Category best sellers: `GET /products?category={slug}&sort=best_selling`.
- Home banners: existing `banner_grid` in `GET /home`.
- Product-card seller/rating data: unchanged.

## Contract and compatibility

This is an additive, backward-compatible adapter release. The public contract remains `v1`. Existing endpoint behavior, opaque IDs, Home sections, filtering, visibility, seller-null behavior, standardized errors and cache diagnostics are preserved.

## Phase 2 boundary

Not implemented here: Identity/Auth, Customer Account, Wishlist, Cart/Guest Session, Checkout, Orders, product-review submission, seller-rating submission, or authenticated Seller Portal functions.
